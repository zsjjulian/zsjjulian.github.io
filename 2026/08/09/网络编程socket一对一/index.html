说明

  • 以下代码是基于TCP协议服务端和客户端所写的最基本的c/s模型，主要实现一对一，该功能无法实现一个服务端对应多个客户端
  • 代码过程中我添加了许多注释，可能会影响观感

整体大致流程

客户端和服务端连接成功后，之后是客户端发送消息，然后服务端接收消息，再把客户端所发出的消息发送给客户端，然后客户端接收。

服务端

  • WSAStartup() 初始化
  • socket(AF_INET, SOCK_STREAM, IPPROTO_TCP) 创套接字
  • bind() 绑定地址
  • listen() 开启监听
  • accept() 接受连接
  • while(1) { recv() -> send() } 循环接收消息和发送消息
  • closesocket() -> WSACleanup() 清理关闭网络库

客户端

  • WSAStartup() 初始化
  • socket(AF_INET, SOCK_STREAM, IPPROTO_TCP) 创套接字
  • connect() 拨号连接
  • while(1) { send() -> recv() } 先发送消息，再接收
  • closesocket() -> WSACleanup() 清理关闭网络库

注意事项

1.字节序转换（大端/小端）

  • 端口号和IP必须用htons() / htonl() 转成网络字节序（大端）
  • 校验：MAKEWORD(主, 副)中，主版本放低字节(LOBYTE)副版本放高字节（HIBYTE）

2.打印字符串缺失

  • 这是 C/C++ 字符串与网络字节流结合时最容易犯的错。
  • 无论服务端还是客户端，在 recv 成功后，需要增加’\0’
  • 为什么必须减 1？ 因为要留一个字节给 \0，防止 cout 打印时越界。

3.端口占用（10048 错误）

  • 现象：bind 失败，错误码 10048（WSAEADDRINUSE）。
  • 在 bind 前，务必加上 setsockopt 设置 SO_REUSEADDR。

4.地址通配符混淆

  • 服务端：sin_addr.s_addr = htonl(INADDR_ANY); （监听所有网卡）
  • 客户端：sin_addr.s_addr = inet_pton(AF_INET, “127.0.0.1”, …); （指定具体 IP）
  • 绝对不能在客户端写 INADDR_ANY！ 否则 connect 报错 10049。

5.IP 地址转换函数

  • 废弃警告：inet_addr 已被微软标记为废弃，且无法区分 255.255.255.255 和错误。
  • 推荐：使用 inet_pton(AF_INET, “IP字符串”, &sin_addr)，记得包含头文件 #include <Ws2tcpip.h>
